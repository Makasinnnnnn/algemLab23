## Краткое описание интерфейса

Программа выполнена как мини-графический редактор с тёмной темой. Слева
расположена прокручиваемая панель управления, справа — область `Canvas` для
рисования многоугольника.

Вершины добавляются кликами мыши по полю. Пока фигура не замкнута, вершины
соединяются ломаной линией. Многоугольник можно замкнуть кнопкой
**«Замкнуть многоугольник»** или двойным кликом по Canvas. Если пользователь
поставил минимум три вершины и сразу нажал кнопку преобразования, программа
автоматически замкнёт многоугольник и выполнит операцию.

На панели задаются параметры:

- `dx`, `dy` — смещение по X и Y;
- `sx`, `sy` — коэффициенты масштабирования;
- `cx`, `cy` — координаты центра или опорной точки;
- `angle` — угол поворота в градусах.

В интерфейсе отображаются количество вершин, состояние многоугольника,
границы фигуры, текущий масштаб рабочей области, последняя операция и текущие координаты мыши. Центр
преобразования `C(cx, cy)` показан крестиком, а оси `x = cx` и `y = cy`
показаны пунктирными линиями.

## Основные функции

- построение многоугольника по кликам мыши;
- замыкание многоугольника;
- смещение вправо и вниз;
- отражение относительно горизонтальной оси `y = cy`;
- отражение относительно вертикальной оси `x = cx`;
- масштабирование относительно точки `C(cx, cy)` по введённым `sx` и `sy`;
- отдельное растяжение относительно точки `C(cx, cy)`;
- отдельное сжатие относительно точки `C(cx, cy)`;
- поворот по часовой стрелке с увеличением;
- поворот против часовой стрелки с уменьшением;
- дополнительное отражение относительно экранных осей `OX` (`y = 0`) и
  `OY` (`x = 0`);
- отмена последнего действия;
- удаление последней вершины до замыкания;
- создание тестового многоугольника;
- установка центра преобразования в центр фигуры;
- вписывание фигуры в окно без изменения её координат;
- масштабирование рабочей области: приблизить и отдалить;
- сдвиг рабочей области влево, вправо, вверх и вниз;
- сброс масштаба и сдвига рабочей области;
- включение и отключение сетки, заливки и номеров вершин.

## Объяснение преобразований

Все преобразования выполняются вручную. Программа хранит вершины в списке:

```python
points = [(x1, y1), (x2, y2), ...]
```

После нажатия кнопки создаётся NumPy-массив координат, по формулам
пересчитываются новые координаты вершин, затем список `points` обновляется, а
Canvas полностью перерисовывается.

### Смещение

```text
x' = x + dx
y' = y + dy
```

Кнопка **«Сместить вправо и вниз»** использует положительные значения `dx` и
`dy`, поэтому фигура перемещается вправо и вниз.

### Отражение относительно X

В экранной системе координат Tkinter ось Y направлена вниз, поэтому отражение
относительно X реализовано как отражение относительно горизонтальной линии
`y = cy`:

```text
x' = x
y' = 2 * cy - y
```

### Отражение относительно Y

Отражение относительно Y реализовано как отражение относительно вертикальной
линии `x = cx`:

```text
x' = 2 * cx - x
y' = y
```

### Масштабирование, растяжение и сжатие

Масштабирование выполняется относительно точки `C(cx, cy)`:

```text
x' = cx + sx * (x - cx)
y' = cy + sy * (y - cy)
```

Если коэффициент больше 1, происходит растяжение. Если коэффициент находится
между 0 и 1, происходит сжатие.

Кнопка **«Масштаб по sx/sy»** применяет введённые значения напрямую. Кнопка
**«Растянуть»** всегда использует коэффициенты больше 1: если в поле введено
`1.2`, используется `1.2`, а если введено `0.8`, используется обратное значение
`1 / 0.8 = 1.25`. Кнопка **«Сжать»** работает наоборот: при `1.2` используется
`1 / 1.2`, а при `0.8` используется `0.8`.

### Поворот

Сначала точка переводится в систему координат относительно центра:

```text
x0 = x - cx
y0 = y - cy
```

Затем выполняется поворот:

```text
x' = cx + x0 * cos(a) - y0 * sin(a)
y' = cy + x0 * sin(a) + y0 * cos(a)
```

В экранной системе координат положительный угол соответствует повороту по
часовой стрелке, отрицательный — против часовой стрелки.

### Поворот с изменением размера

Кнопка **«Повернуть по часовой + увеличить»** сначала поворачивает фигуру на
положительный угол `angle`, затем масштабирует её относительно той же точки
`C(cx, cy)`. Если `sx` или `sy` меньше либо равны 1, используется коэффициент
увеличения `1.1`.

Кнопка **«Повернуть против часовой + уменьшить»** сначала поворачивает фигуру
на отрицательный угол `angle`, затем уменьшает её. Если `sx` или `sy` не
попадают в диапазон от 0 до 1, используется коэффициент уменьшения `0.9`.

## Управление рабочей областью

Рабочая область поддерживает отдельный масштаб и сдвиг вида. Эти операции не
изменяют координаты вершин многоугольника и не относятся к геометрическим
преобразованиям фигуры. Они нужны только для удобного просмотра.

- **«Приблизить»** увеличивает масштаб отображения.
- **«Отдалить»** уменьшает масштаб отображения.
- **«Сдвинуть влево/вправо/вверх/вниз»** перемещает видимую область.
- **«Сбросить вид»** возвращает масштаб 100% и нулевой сдвиг.
- **«Вписать фигуру в окно»** подбирает масштаб и сдвиг так, чтобы вся фигура
  была видна на Canvas.

Колесо мыши над Canvas также изменяет масштаб рабочей области.
