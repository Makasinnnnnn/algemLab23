# Краткое пояснение к лабораторной работе №2

## 1. Как работает программа

Программа открывает окно Tkinter размером примерно 900x600 пикселей. В верхней
части находится панель кнопок, а основную часть занимает белое поле `Canvas`.
Пользователь кликает по полю, после чего программа сохраняет координаты точки,
перерисовывает контрольные точки и соединяет их ломаной линией.

Кнопка **«Очистить»** удаляет все точки и линии. Кнопки **«Показать ломаную»**
и **«Показать сплайн»** позволяют переключаться между исходной ломаной и
полученной гладкой кривой. При нажатии **«Показать сплайн»** программа сама
строит сплайн по введенным точкам, если он еще не был рассчитан.

## 2. Как задаются точки

Точки задаются кликами левой кнопкой мыши по области рисования. Координаты
клика берутся из объекта события Tkinter: `event.x` и `event.y`. Каждая точка
сохраняется в списке:

```python
[(x1, y1), (x2, y2), (x3, y3), ...]
```

После каждого клика точка отображается маленьким кругом. Если точек две или
больше, соседние точки соединяются прямыми отрезками, образуя ломаную.

## 3. Как ломаная превращается в сплайн

Для построения сплайна программа берет контрольные точки группами по четыре:
`p0`, `p1`, `p2`, `p3`. Между точками `p1` и `p2` вычисляется много
промежуточных точек при значениях параметра `t` от 0 до 1.

Для каждой промежуточной точки используется формула Catmull-Rom:

```text
P(t) = 0.5 * (
    2 * P1
    + (-P0 + P2) * t
    + (2*P0 - 5*P1 + 4*P2 - P3) * t^2
    + (-P0 + 3*P1 - 3*P2 + P3) * t^3
)
```

На краях первая и последняя контрольные точки дублируются. Это нужно, чтобы
кривая корректно начиналась в первой точке и заканчивалась в последней. Все
найденные промежуточные точки соединяются короткими отрезками, поэтому на
экране получается визуально гладкая кривая.

Если точек меньше двух, сплайн не строится. Если точек ровно две, программа
оставляет обычный отрезок.

## 4. Почему выбран Catmull-Rom spline

Catmull-Rom spline хорошо подходит для этой задачи, потому что он строит
гладкую кривую по последовательности контрольных точек и проходит через эти
точки. Пользователю не нужно задавать дополнительные касательные или параметры:
достаточно поставить точки мышью, а программа автоматически сглаживает ломаную.

Этот алгоритм прост для реализации, наглядно показывает преобразование ломаной
в сплайн и удобно вычисляется с помощью NumPy.
